# course-2026-hw-1-go
Домашнее задание №1 по курсу ЦЦР

## Как сдать домашнее задание

1. Сделайте форк этого репозитория на GitHub.
2. Выполните все три задания в своём форке и отправьте изменения на GitHub.
3. Дождитесь зелёной галочки от GitHub Actions в своём репозитории. Все три проверки должны пройти.
4. Напишите в выделенный канал курса, что вы выполнили ДЗ №1, и приложите ссылку на свой репозиторий, чтобы работу взяли на проверку.
