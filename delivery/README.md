# Тарифы доставки · 4 балла

Пункт выдачи рассчитывает стоимость доставки нескольких заказов. В `internal/delivery/delivery.go` уже объявлен интерфейс `Tariff` с методом `Cost(weightGrams int) int`. Метод принимает вес одного заказа в граммах и возвращает стоимость доставки в целых рублях.

## Реализуйте два тарифа

- `Pickup` — самовывоз, стоимость всегда равна 0.
- `Courier` — курьерская доставка. Первый начатый килограмм стоит 150 рублей, каждый следующий начатый килограмм добавляет 50 рублей. Для веса 1000 г стоимость равна 150 рублям, для 1001 г — 200 рублям, для 2000 г — тоже 200 рублям.

Оба тарифа должны реализовывать `Tariff` как значения: `Pickup{}` и `Courier{}`. Веса на входе лежат в диапазоне от 1 до 30 000 г.

## Рассчитайте общую стоимость

Реализуйте `TotalDelivery(weights []int, tariff Tariff) int`. Вызовите `tariff.Cost` для каждого веса в порядке входного среза и сложите результаты. Применяйте переданный тариф через его метод, чтобы функция работала с любым типом, реализующим `Tariff`. Для пустого среза верните 0.

```go
TotalDelivery([]int{1000, 1001}, Courier{}) // 350
TotalDelivery([]int{1000, 1001}, Pickup{})  // 0
```

## Проверка

Из корня репозитория запустите `go -C delivery test -v ./...`. Тесты проверяют оба тарифа, границы между килограммами и расчёт с тарифом, объявленным в тесте. Заготовка компилируется, часть тестов ожидаемо падает до реализации.
