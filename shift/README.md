# Сводка за смену

Напишите консольную программу для пункта выдачи. Она получает суммы заказов за смену и выводит их общую сумму, максимальную сумму заказа и количество заказов на сумму от 1000 рублей включительно.

## Ввод и вывод

Первое число на входе — количество заказов `n` от 0 до 1000. За ним идут ровно `n` целых сумм в рублях от 0 до 100 000. Каждое число записано десятичными цифрами от `0` до `9`. Числа разделены пробельными символами. Начальные и конечные пробелы и переводы строк допустимы. Конец ввода определяется по EOF.

Выведите три целых числа в указанном порядке, разделённые одним пробелом, и завершите строку переводом строки. Если заказов нет, выведите `0 0 0`.

Если данные отсутствуют, число записано в неверном формате или выходит за границы, сумм меньше или больше заявленного количества либо чтение завершилось ошибкой, оставьте `stdout` пустым. Напишите в `stderr` сообщение о причине и завершите программу с кодом 1.

Если запись результата в `stdout` вернула ошибку, сообщите о ней в `stderr` и завершите программу с кодом 1. Точный текст сообщений об ошибках выбираете вы.

Пример ввода

```text
4
700 1000 1300 0
```

Ожидаемый вывод

```text
3000 1300 2
```

## Что реализовать

- В `internal/summary/summary.go` реализуйте функцию `Summarize(amounts []int) (total, max, largeCount int)`. Она вычисляет три показателя по срезу сумм. Для пустого среза все показатели равны нулю.
- В `cmd/shift/main.go` реализуйте `main`. Импортируйте пакет `shift/internal/summary`, прочитайте данные со стандартного ввода, вызовите `summary.Summarize` и напечатайте результат.

## Как проверить решение

Из корня репозитория выполните:

```sh
cd shift
go test -v ./...
```

Тесты в `internal/summary` проверяют функцию расчёта, а тесты в `cmd/shift` запускают собранную программу. Заготовка компилируется, а часть тестов ожидаемо падает до реализации.

Для ручного запуска из каталога `shift` используйте `go run ./cmd/shift`.

Задание рассчитано на запуск под Linux. При ручном вводе с клавиатуры завершите ввод нажатием Ctrl+D.
