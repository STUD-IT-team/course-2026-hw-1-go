# Заказ и его состояние · 3 балла

Опишите структуру `Order` для пункта выдачи. В закрытых полях храните номер заказа, имя получателя, сумму в целых рублях и текущее состояние. Заполните заготовку в `internal/order/order.go`.

## Данные заказа

`NewOrder(id, recipient string, amount int) *Order` создаёт заказ в состоянии `StatusPending`. Номер и имя непустые, сумма лежит в диапазоне от 0 до 100 000 рублей. В конструктор передают корректные данные.

Методы `ID() string`, `Recipient() string` и `Amount() int` возвращают данные заказа. Они сохраняются при любом переходе. Метод `Status() Status` возвращает текущее состояние, а `IsIssued() bool` возвращает `true` только в состоянии `StatusIssued`.

## Переходы

У заказа четыре состояния: ожидает подготовки (`StatusPending`), готов к выдаче (`StatusReady`), выдан (`StatusIssued`) и отменён (`StatusCancelled`). Используйте тип `Status` и константы из заготовки.

| Метод | Из каких состояний доступен | Новое состояние |
| --- | --- | --- |
| `MarkReady() bool` | `StatusPending` | `StatusReady` |
| `Issue() bool` | `StatusReady` | `StatusIssued` |
| `Cancel() bool` | `StatusPending`, `StatusReady` | `StatusCancelled` |

Каждый метод возвращает `true`, если состояние изменилось. В остальных случаях метод возвращает `false` и сохраняет текущее состояние. Каждый заказ хранит собственное состояние, даже если у двух заказов одинаковый номер.

```go
o := NewOrder("A-42", "Анна", 1500)
o.Issue()    // false
o.MarkReady() // true
o.Issue()    // true
o.IsIssued() // true
o.Cancel()   // false
```

## Пакетная выдача

Реализуйте `IssueBatch(orders []*Order, limit int) (issuedIDs []string, total int)` в `internal/order/batch.go`. Функция выдаёт готовые заказы в пределах общей суммы `limit` в рублях и возвращает номера выданных заказов и их общую сумму.

- Просматривайте заказы в порядке входного среза. Пропускайте заказы, которые не готовы к выдаче.
- Если сумма готового заказа помещается в оставшийся лимит, вызовите `Issue`, добавьте номер в результат и учтите сумму. Если заказ слишком дорогой, оставьте его готовым и продолжайте просмотр.
- Нулевой заказ можно выдать даже при исчерпанном лимите. Если один и тот же объект встречается в срезе несколько раз, он может быть выдан только один раз. Разные объекты с одинаковым номером обрабатываются отдельно.
- При пустом срезе или когда выданных заказов нет, верните срез длины 0 и сумму 0. Лимит неотрицательный, элементы среза — указатели на заказы, созданные через `NewOrder`.

Например, при лимите 1000 рублей и трёх готовых заказах `A` на 700, `B` на 400 и `C` на 300 функция вернёт `[]string{"A", "C"}` и `1000`. Заказ `B` останется готовым к выдаче.
